    Options

    Off (normal): Volume Fix ignores each clip's current volume setting and matches clips purely by how loud they measure. The quietest clip ends up at 100% and every other clip is set to whatever makes it sound just as loud. A clip someone had set to 30% gets reset to its matching level, which can be higher or lower than 30%.

    On: each clip's existing setting is kept as a deliberate offset on top of the matching. If a presenter set a clip to 50% (−6 dB) to sit it under their voice, it stays 6 dB quieter than the rest after normalising, instead of being raised to match.

    Turn it on only for decks where someone has already balanced clips on purpose. Most decks just carry PowerPoint's default (80% for video), and there it would only lower every clip by the same amount, so leave it off.

    Volumes are set with PowerPoint's volume curve: . Calibrate it with a loopback recording.

    Playing clips from other software? Copy every embedded audio and video file into a folder, one subfolder per presentation, named by slide (slide16-clip2.mov), with volume-fix-gains.txt listing the gain each file needs. This doesn't make the normalised presentations; use Save below for those.
