What Volume Fix does

It measures the loudness of every audio and video clip in a set of PowerPoint files, using the broadcast standard (ITU-R BS.1770), over just the part of each clip that actually plays. The quietest clip becomes the reference. Every other clip is turned down to match by changing PowerPoint's own per-clip volume setting.

Nothing is re-encoded, and your original files are never changed: you get copies named name_normalized.pptx. With the desk lined up once, every clip in the batch plays at the same loudness.

Preparing a batch

  1. Add presentations. Drop all the decks for the event (or a folder of them) onto the page. Put everything that will play through the same desk channel in one batch, so they share one reference level.
  2. Review. Check the notes column. Cut by more than 15 dB means a clip is much louder than the quietest one: worth a listen. No audio, Muted and Silent clips are left alone. Press ▶ to hear any clip at its new level, and use the ▶ next to the reference level to hear the matching tone.
  3. Check the media controls warning. If a deck with video has PowerPoint's Show media controls on, moving the mouse over a playing video (including the preview in Presenter View) can put a progress bar over it. To turn it off, open the deck in PowerPoint: Slide Show → Set Up Slide Show → untick Show media controls.
  4. Choose an output folder and save. You get the normalised decks, a reference tone deck, and a batch log (log_….html) listing every clip, slide by slide.

Saved decks are marked as downloaded from the internet, so PowerPoint opens them in Protected View and asks before you can edit. They still present normally. To avoid the prompt, add the output folder as a trusted location: in PowerPoint, File → Options → Trust Center → Trust Center Settings → Trusted Locations → Add new location.

Setting up the playback machine

Matched levels only stay matched if nothing changes them between PowerPoint and the desk. On the Windows machine that plays the show:

  • Turn off Loudness Equalization and other audio enhancements: Settings → System → Sound → your output device → Audio enhancements: Off.
  • Turn off spatial sound on that device.
  • Set the Windows volume and PowerPoint's own volume once, and don't touch them during the show.
  • Keep the same output device, and the same sample rate, as when you line up.

Lining up the desk

The tone deck (REFERENCE_TONE_…pptx) plays a steady 1 kHz tone at exactly the loudness of the quietest clip, the level every clip has been matched to. It opens in a window, so it's unlikely to end up on the projector, and it loops until you stop it.

  1. Play the tone deck through the same output as the show.
  2. Set the console input so the tone sits on your reference mark.
  3. Every normalised clip in the batch will now play at that level.

No time for the tone? Set the level off the first clip: the rest will match it. The mono and stereo slides of the tone deck should read the same; PowerPoint plays mono files at full level on both sides.

Playing clips from other software

If clips will run from separate playout software instead of PowerPoint, open Options → Save all media files. Every embedded audio and video file is copied into a folder, one subfolder per presentation, named by slide (slide16-clip2.mov). Alongside them, volume-fix-gains.txt lists the gain to set in your playout software for each file: the quietest is 0.0 dB, and the rest are cuts. The ⤓ button on a clip in the review table downloads just that file. The presentations aren't changed.

Leaving clips out and re-running

Tick Skip on any clip that shouldn't be normalised, for example music meant to sit under a voice. It keeps its current volume and is left out when choosing the reference. To re-run a batch later with the same choices, open its batch log, tick the clips there and press Export opt-out list, then load that file in Options → Load opt-out list.

Keep each clip's original volume as an offset (in Options) is for decks where someone has already balanced clips on purpose; press its ? for details. Leave it off for normal use.

Using it with no internet

After you've opened Volume Fix once online, it works offline in the same browser: every part of the app is kept on your computer. For quick access at a venue, install it: use Install app at the bottom of the main page, or the install icon in the address bar. It then opens in its own window, like any other program. Chrome or Edge is required.

Calibration and PowerPoint versions

Volume Fix needs to know how many decibels a volume setting like "40%" really gives. On Office 365 PowerPoint 16 this has been measured: the setting is a plain linear amplitude scale (50% = −6 dB, 10% = −20 dB), and it's built in. If you show with a different PowerPoint version, the calibration page measures yours in a couple of minutes using a loopback recording.

Privacy

Everything happens in your browser. Your presentations are read from and written to your own computer, and nothing is uploaded. The site's security policy only allows it to connect to itself, and the code it runs is published, readable, on GitHub.
